## 🐛 Bug 修復記錄

### Bug #1: Tuple 索引錯誤

**症狀**:

```
AttributeError: 'float' object has no attribute 'items'
```

**根本原因**:

- `format_retrieved_text()` 預期的 Tuple 結構: `(id, user_id, date, foods, calories, meal_type, ...)`
- `get_previous_meals()` 實際返回: `(id, date, foods, calories, portion_size, meal_type)`
- 索引不匹配導致 `meal[3]` 被當作 `foods` (實際是 `calories`)

**修復方案**:

```python
# 修復前
date_str = meal[2]    # ❌ 實際是 foods dict
foods = meal[3]       # ❌ 實際是 calories float
calories = meal[4]    # ❌ 實際是 portion_size

# 修復後
date_str = meal[1]    # ✅ 正確
foods = meal[2]       # ✅ Dict[str, float]
calories = meal[3]    # ✅ float
portion_size = meal[4] # ✅ float
meal_type = meal[5]   # ✅ str
```
