## 📋 功能概述

`/recommend` 命令整合 RAG (Retrieval-Augmented Generation) 推薦引擎,根據用戶的飲食歷史提供個人化的飲食建議。

### 核心特點

1. **個人化分析**: 基於用戶真實歷史記錄
2. **RAG 增強**: 檢索 → 格式化 → 增強 → 生成
3. **餐次定制**: 可指定特定餐次(早餐/午餐/晚餐/點心)
4. **趨勢識別**: 自動識別飲食模式和問題
5. **具體建議**: 提供可執行的改善方案

---

## 🎯 命令用法

### Discord 斜槓命令語法

```
/recommend [餐次] [天數]
```

### 參數說明

| 參數   | 類型 | 必填 | 預設值 | 說明                      |
| ------ | ---- | ---- | ------ | ------------------------- |
| `餐次` | 字串 | ❌   | 無     | 想要建議的餐次類型        |
| `天數` | 整數 | ❌   | 7      | 分析最近幾天的記錄 (1-30) |

### 餐次類型

- **早餐**: `早餐`, `breakfast`, `早`
- **午餐**: `午餐`, `lunch`, `午`, `中餐`
- **晚餐**: `晚餐`, `dinner`, `晚`
- **點心**: `點心`, `snack`, `零食`
- **不指定**: 分析整體飲食

## 🤖 RAG 推薦流程

### 1. 資料檢索 (Retrieval)

```python
# 獲取前序餐點
previous_meals = get_previous_meals(user_id, meal_type)

# 獲取歷史統計
past_analysis = get_past_days(user_id, days)
```

**檢索內容**:

- ✅ 今日前序餐點 (如果指定餐次)
- ✅ 過去 N 天的所有餐點記錄
- ✅ 營養趨勢統計 (平均值、最大值、分布)
- ✅ 餐次分布比例

### 2. 文本格式化 (Format)

```python
retrieved_text = format_retrieved_text(
    previous_meals=previous_meals,
    past_analysis=past_analysis,
    days=days
)
```

**格式化結果**:

```
飲食歷史檢索結果:

今日前序餐點:
1. 早餐 (07:30): 漢堡(500 kcal), 薯條(300 kcal) - 總計 800 kcal
2. 午餐 (12:00): 炸雞(600 kcal), 可樂(150 kcal) - 總計 750 kcal
今日已攝取總熱量: 1550 kcal

過去 7 天飲食統計:
- 總餐數: 21 餐
- 平均每日熱量: 2200 kcal
- 最高每日熱量: 2800 kcal
- 餐次分布: 早餐 35%, 午餐 35%, 晚餐 30%
```

### 3. Prompt 增強 (Augmentation)

```python
prompt = f"""
你是一位專業的營養師...

{retrieved_text}

當前餐點資訊:
- 餐次: {meal_type}
- 食物: {current_foods}
- 熱量: {current_calories} kcal

請提供個人化的飲食建議...
"""
```

### 4. AI 生成 (Generation)

```python
recommendation = gemini_client.generate_content(prompt)
```

**生成內容結構**:

- 🔍 **飲食分析**: 當前狀況評估
- 💡 **健康建議**: 具體改善方案 (3-5 項)
- 🍎 **推薦食物**: 適合的食物選擇 (3-4 項)
- ⚠️ **注意事項**: 重要提醒

### 5. Fallback 機制

如果 API 失敗或無歷史記錄:

```python
recommendation = _generate_rule_based_rag_recommendation(
    user_id, meal_type, current_foods, current_calories
)
```

1. **定期使用**: 每天使用 `/analyze` 記錄餐點後,使用 `/recommend` 獲取建議
